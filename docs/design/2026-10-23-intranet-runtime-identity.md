## 用户体验契约

1. 内网版“使用工具”默认只有 CodeAgent、Claude Code、Codex、DSH、Pi 五种 harness。内部已有 `claude` 等工具 ID 保持兼容，显示名不承担绑定身份。
2. 一个 CodeAgent 工具可以承载宪宪、砚砚、墨墨等多个独立角色；推荐身份在角色推荐层展开，不伪装为多个程序。各自成员 ID、昵称、职责和创建回执不合并。
3. 已有成员的命令、参数、模型、连接、插件引用继续保留；重新检测不修改它们。当前精确绑定与普通工具目录分开，切换同一种工具不重置配置，切出再返回优先恢复原草稿。
4. 插件仍通过现有插件目录及授权入口接入。相同可执行程序不等于相同插件授权，不按文件名或 `clientId=acp` 合并授权。
5. 聊天中的人类标签统一使用“显示名 · 昵称”，没有昵称或昵称重复时省略重复部分；例如“小鲸鱼 · 鲸鲸”。@ 候选、插入文本、已发消息中的提及和回复头保持一致。
6. 稳定角色 ID 仍用于会话、配置、路由和历史关联。历史 `@dsh` 仍可识别和显示，不批量改写历史文本；人类标签冲突时不能误投给另一个角色。
7. 只改变用户提及的显示与解析兼容；A2A 的既有别名和路由契约不扩大。角色改名不重建角色或原生会话。

## 工作单元与验证

| 单元 | 位置 | 验证结果要求 |
| --- | --- | --- |
| 原生工具目录 | native discovery 与 API | 单个 CodeAgent 工具、五种内网工具、公共目录兼容、精确绑定与插件边界 |

| 合流回归 | 桌面镜像/网络桥、Pi ACP、MCP 环境引用 | 保留首启诊断与取消、持久恢复、首轮输出和凭据引用边界 |

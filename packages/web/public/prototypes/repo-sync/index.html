原型边界

Git 与平台命令适配

Git 负责提交对象、分支和文件树。Issue 与 PR 需要内部平台 CLI 或 API；标准 Git 没有创建这些对象的命令。

当前界面将它们统一展示为 repo-sync issue / pr 占位命令。落地时可接入 codehub-cli，Git 部分继续使用 Git Bash。

此原型只改变本地演示状态，不执行真实 Git、平台命令或网络同步。
